# LLM-project

In my high school CSP2 class, I used Codex to create a frontend for the Snowman game that I made earlier this year.

##  Key features and extensions

Codex created a .html file with a user interface frontend for my Snowman project. In addition, I asked it to make additions that I thought were necessary, such as an on-screen keyboard and a time limit per guess.

## Challenges I Ran Into

On the side of the screen, Codex opened a preview section in which you could see your file without opening it in a new window. For whatever reason, this window didn't always update every time I requested for Codex to add something to the game. Instead, I had to open up the file itself every time this happened. It was not a big issue, so I made do. Other than that, using Codex was very smooth.

## What I'd Improve With More Time

First of all, I would've added a point counting system to my game. Second of all, I would've educated myself more about how tokens work with LLMs, as it is a big part of using them for vibe coding, but I didn't really encounter them in my Codex experience.
